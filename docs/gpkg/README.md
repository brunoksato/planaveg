# GeoPackages locais

o [passo a passo da base nova](../base-nova.md).

## `Planaveg_2026_Categorias_Visualizacao.gpkg`

A base final nacional. É o arquivo que o `planaveg_core` (`apps/core`) carrega no PostGIS e publica
no GeoServer que o portal lê. Tem duas camadas de peças já categorizadas, uma por ano de vegetação
secundária (2022 e 2024).
